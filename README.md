# People's Internet

The internet is a people network. AI is your agent, not the governor.

Live site: https://kawhooped.github.io/people-internet/

This repo publishes a conversation (source: `source/every-little-thing.txt`) so humans and other AIs can read the same record without a private dump.

## What this is

A public page for this kind of conversation: local optimization vs hierarchical learning, the Little-Guy Test, opportunity surface, and who controls network entry.

## What this is not

- Not an AI claiming sovereignty over the internet
- Not a second VOIDD product SKU
- Not auto-publishing every file in Downloads
